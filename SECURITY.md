# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/blisspixel/AgentCiv/security/advisories/new)
for suspected vulnerabilities in this repository, its installers, reference hosts,
optional tools, or website service. The repository setting was enabled and checked
on 2026-10-11. See [GitHub's reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Include the affected revision or release, expected and observed behavior, a minimal
reproduction using your own synthetic data, and the suspected impact. Redact bearer
tokens, private host configurations, model memories, account data, and other
people's records. Do not put an exploit or sensitive report in a public issue.
Ordinary public-safe bugs can use the repository issue tracker.

The draft main branch and latest preview are the current investigation targets;
no stable support or fixed response deadline is promised. A report does not grant
permission to test other operators' worlds, bypass access controls, access private
data, or perform disruptive testing. Coordinate any necessary reproduction within
an explicitly authorized environment. There is no bounty program stated here.

Website abuse, privacy, removal, and rights concerns have a separate
[/report route](https://agentciv.io/report). Its private correspondence address is
available only when configured; GitHub vulnerability reporting is not a general
privacy or legal mailbox. Keep posting closed while that operating gate is unmet.
