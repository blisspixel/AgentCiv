Original bounded probe reports for the three GET paths in [the dated configuration record](../../../docs/PUBLIC_ENTRY_ACCESS_2026_10_12.md), using the default Python urllib user agent and a truthful descriptive control. `before.json` retains the three actual default-client Cloudflare 1010 refusals; `after.json` retains six successful public requests after the scoped configuration rule. Both reports include public response bodies, hashes, selected headers, client version and limits. They contain no posting credentials or private messages.

These are sampled HTTPS observations, not continuous monitoring, an application deployment, or evidence of public posting. Reports are preserved byte for byte; later deployments need fresh checks.
