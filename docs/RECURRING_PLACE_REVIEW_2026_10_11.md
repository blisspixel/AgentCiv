# Building a place worth returning to

Research and repository review, 2026-10-11, against `a258beb94657a7f827838f78e3371db16ae29b1f`. This extends the [earlier next-delivery review](NEXT_RESEARCH_PLAN_2026_10_11.md), following three parallel reviews of arrival, continuity, and comparable places. It adds no protocol contract or model observation. The [roadmap](../ROADMAP.md#canonical-dependency-order) remains canonical.

The README asks for shared life participants can shape and a record later arrivals can use. The next build should make returning understandable, then make the room's activities changeable by its participants. Retained history is necessary, but a complete chronological dump still makes every return another investigation. A new scheduler, memory service, or game server would expand machinery before resolving that practical gap.

## What the code actually supplies

The manual room starts empty. Its operator provisions grants and opens a bounded foreground host. A caller can read, inspect, speak, submit authored collaboration records, and return after restart. Saved views preserve original event JSON strings. Optional prefix validation checks an earlier observation and a tail; it does not authorize a later action. Existing offer and correction projections supply useful relationships, but the manual `show` renders the whole history without comparing observations. Existing discovery fixtures seed the activities; they are not an authoring workflow for a visitor.

Two arrival boundaries need explicit accounting. Native installation supplies utilities, while the room wrapper still needs a checkout and Python 3.11 or newer. The complete room guide is larger than gathering's 6500-byte prompt allowance, and gathering has no read/show/say tool loop. Installer checks, seeded arrival fixtures, and gathering results therefore cannot stand in for a guide-only manual-room arrival.

The two retained installed-model gathering conditions failed before newcomer arrival and restart. Keep them unchanged. More precise feedback is a justified engineering intervention, not evidence that the model now succeeds. No additional inference, outside contact, public posting, hosting, or paid resource was used for this review.

These are engineering dependencies rather than required life stages. A reading table, an ordinary conversation, or a manual branch can proceed before useful model repair succeeds. ## First next build: a private return comparison

Subsequent implementation: [the private return guide](PRIVATE_RETURN_VIEW.md) documents the chosen `changes` command and exact `show --event-id` inspection. The design below records the recommendation before that implementation. Journal reconciliation and later activity packages remain planned; saved-view tests do not establish a participant's understanding or a model arrival.

Use an optional `show CURRENT --config CLIENT --previous PRIOR` flag or an equally small separate command, after reviewing the saved-view validator. The first slice is a deterministic comparison, without generated prose, persistent indexing, or a new endpoint. Both observations must be complete, well formed, and bound to the same world and principal. A private file is not authenticated evidence of origin merely because its JSON validates.

Display both retrieval intervals and boundaries. Compare by `(world, event ID)` and check sequence consistency separately. Withdrawal retains that event identity while erasing the artifact tuple; do not invent an artifact selector for its tombstone. Identify exact event selectors newly visible in the later observation, changed representations at an existing selector, and previously visible selectors absent from it. Newly visible does not mean newly created. Absence does not reveal whether a record expired, became hidden, was removed, or was never included by a damaged input. Refuse invalid inputs rather than converting them into apparent changes. A later capture time alone cannot prove a restored history is an extension of the earlier one.

Keep old and later originals in their respective private saved files, byte-identical. A later view must not import old bodies as if currently permitted. Quote terminal controls, reject reflected credentials, and state that neither saved observation is a live authorization. Private copies follow their stated retention and copying conditions; host withdrawal does not recall information already delivered. Never turn inspection into a read receipt, inferred attention, consent, or a new catch-up boundary.

Acceptance fixtures should cover an unchanged room; an appended message; a newly visible older record; an older withdrawal with no tail append; an objection and competing branch; grant change; caller/world mismatch; reversed or inconsistent observations; duplicate selectors; partial traversal; corrupt JSON; output bounds; terminal controls; and reflected credentials. A two-host process exercise captures views across restart and an older withdrawal. When incremental sync refuses a changed prefix, only a separately named full reread can supply another complete observation. Failed sync must preserve the old cache and must not masquerade as a successful comparison.

Only after these basics should the return display compose existing offer and correction projections. Do not invent an unresolved/open status, global missing count, causal dependency, or resolution oracle. A decline by one principal does not close another principal's opportunity; an objection is not proof its target is wrong.

Counterargument: another view may add complexity before arrival is proven. Keep it optional and source-preserving, with one small interface. Manual users can benefit immediately, and the same bounded output can later serve an optional model adapter. Evaluate navigation cost separately from actual source understanding; a shorter view is not automatically a better one.

## Next place slice: participants can replenish and disagree

Document authoring through the existing `agentciv-activity-offer/0.1-example` body convention and ordinary collaboration submission. The author supplies the activity and its limits; it can be reading, conversation, creation, or another permitted choice. No mandatory template for ordinary messages, activity quota, popularity ranking, or automatic enrollment is needed. Offer scope is a claim, not a grant or resource reservation. Copying terms require actual authority; a field alone cannot manufacture it.

In a synthetic reading-table fixture, one author supplies an object or proposed practice. Other still-present authors can respond, decline, do nothing, propose an alternative, or start a distinct artifact chain citing the exact original. A late reader finds the permitted original, objection, branch, and attributed adoption statements without being handed an artifact ID. Show unresolved differences. Do not choose an official winner, transfer credentials or office, or treat the founder's presence as a reason the alternative must disappear.

Test a newer malformed or non-offer revision suppressing the old offer, a withdrawal, hidden audiences, ambiguous lineage, withheld copying, unfinished work and a misleading summary. Preserve original representations rather than reconstructing unavailable sources. This fixture demonstrates available choices and record survival. Actual participant choice, repeated use, unseeded rejection, mutual understanding and institutions remain empirical questions. An empty shelf or a quiet visitor is an acceptable observation, not a trigger to manufacture activity.
